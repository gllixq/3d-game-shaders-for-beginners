# 漫反射与高光

漫反射和高光在 `base.frag` 的同一盏灯循环里计算，用的是同一条法线，然后分开累加。漫反射回答「这个表面朝不朝向这盏灯」，高光回答「相机看不看得到这盏灯的反射」。默认开着 Blinn-Phong 和菲涅尔（按键 `0` 和 `3`）。

章节里的公式是教学简化。下面每一条都对着 `demonstration/shaders/fragment/base.frag` 和 `demonstration/shaders/vertex/base.vert`。

## 向量在哪一层准备好

顶点着色器把位置和法线变到观察空间。之后所有点积都在这个空间里做，原点是相机。

```glsl
vertexPosition = p3d_ModelViewMatrix * p3d_Vertex;
vertexNormal   = normalize(p3d_NormalMatrix * p3d_Normal);
```

`p3d_NormalMatrix` 是 ModelView 逆转置的左上 3×3。法线不直接乘 ModelView，否则非均匀缩放会把法线带歪。切线和副切线同样乘这张矩阵，供法线贴图使用。

片元里每盏灯现算四个单位向量：

| 符号 | 代码 | 指向 |
| --- | --- | --- |
| L | `normalize(position.xyz - vertex.xyz * position.w)` | 从片元指向灯 |
| V | `normalize(-vertexPosition.xyz)` | 从片元指向相机 |
| R | `normalize(-reflect(L, N))` | 光在法线上的反射方向 |
| H | `normalize(L + V)` | L 和 V 的角平分线 |

方向光没有位置。Panda3D 把 `position.w` 设为 0，`position.xyz` 设为 `-direction`，于是 `L` 就是这个方向，所有片元共用。点光和聚光的 `w` 是 1，`L` 才是「灯的位置减片元位置」。

`reflect(I, N)` 的定义是 `I - 2(N·I)N`。传入的是从片元指向灯的 L，再取负，得到的才是常用的反射向量 `R = 2(N·L)N - L`。高光强度是 `R·V`（Phong）或 `N·H`（Blinn-Phong）。

法线 `N` 三选一：粒子用世界 +Z 变到观察空间；法线贴图打开时，把 `p3d_Texture1` 从切线空间乘 TBN 变过来；否则用顶点法线。漫反射和高光读的是这同一个 `N`。贴图一变，两边一起变。

## 漫反射

循环开始前先把漫反射贴图 `p3d_Texture0` 解码进线性空间。粒子再乘顶点色。UV 用的是 `p3d_MultiTexCoord1`，和镜面贴图同一套坐标。

```glsl
diffuseColor.rgb = pow(texture(p3d_Texture0, diffuseCoord).rgb, vec3(2.2));
Id = dot(N, L);
if (Id < 0.0) continue;
```

`N` 和 `L` 都是单位向量，点积在 -1 到 1。小于 0 表示灯在表面背面，这盏灯的漫反射和高光都不要。`continue` 发生在高光计算之前，所以背面不会留下 Blinn-Phong 那种「灯在背后、半角仍朝向法线」的亮斑。

卡通打开时，强度再被 `smoothstep(0.1, 0.2, Id)` 收成接近 0 或 1 的台阶。没开卡通就保持原来的 `Id`。

一盏灯的漫反射是：

```text
diffuseTemp = clamp(albedo_linear * light.diffuse_linear * Id, 0, 1)
```

灯的颜色也先 `pow(..., 2.2)`。乘积发生在线性空间，再夹到 0 和 1。章节里还有一次 `clamp(diffuseTemp, 0, albedo)`，把结果限制成不超过贴图本身。演示里没有这第二次夹取。灯色或强度如果把乘积推过 1，结果可以比贴图更亮，只是单盏灯不超过 1。

多盏灯是相加，总和不再夹取。顶点着色器允许 4 盏灯（一盏方向光加三盏窗户聚光），四份漫反射叠在一起可以超过 1。后面的泛光阈值是 0.6，这些亮部会被晕开。

## 高光

高光不乘漫反射贴图。它乘的是灯的高光色和镜面贴图。

```glsl
Is = blinnPhong
   ? clamp(dot(N, H), 0, 1)
   : clamp(dot(V, R), 0, 1);
Is = cel ? smoothstep(0.9, 1.0, Is) : Is;

specularTemp = light.specular_linear
             * pow(Is, specularMap.g * 127.75)
             * materialSpecularColor;
specularTemp = clamp(specularTemp, 0, 1);
```

两种模型只换强度从哪一个点积来：

- Phong：相机方向和反射方向有多齐。对齐时是 1，差一点点就掉得很快。
- Blinn-Phong：法线和半角有多齐。H 与 N 重合时，V 正好沿着 R，两种模型都是 1。其他角度 Blinn 往往还大于 0，Phong 已经是 0。高光形状更扁。

指数是镜面贴图 G 通道乘 `MAX_SHININESS`（127.75），不是 `p3d_Material.shininess`。G 为 1 时高光很紧。G 为 0 时指数是 0，`Is > 0` 的地方 `pow` 得 1，高光铺满整个被照到的半球，而不是「没有高光」。没有高光要靠 R 通道为 0，并且菲涅尔关掉。

卡通把 `smoothstep` 的下沿放在 0.9，只留下高光最亮的芯。

`pow(0, 0)` 在 GLSL 里没有定义。G 通道为 0 且 `Is` 也是 0 时会走到这里。被照亮的像素 `Is` 通常大于 0，实际画面里更常见的是「G 为 0 则高光铺满」。

## 镜面贴图的三个通道

`p3d_Texture2` 用漫反射那套 UV 采样。三个通道各管一件事，和章节里「红和蓝一起控制随视角变化的高光量」不是同一种分法。

| 通道 | 演示里的用途 | 为 0 时 |
| --- | --- | --- |
| R | 高光颜色，复制成 RGB | 菲涅尔关闭时高光为黑 |
| G | 光泽，乘 127.75 当指数 | 指数为 0，被照到的地方高光是满的 |
| B | 菲涅尔指数，乘 5 | 菲涅尔曲线变成 `pow(x, 0)`，掠射角立刻拉满 |

菲涅尔不改指数，只把 R 通道的颜色往白色拉：

```glsl
F = dot(blinnPhong ? H : V 所用的那个向量, V);
F = pow(1.0 - max(F, 0.0), specularMap.b * 5.0);
materialSpecularColor = mix(vec3(specularMap.r), vec3(1.0), clamp(F, 0, 1));
```

正对表面时 `N·V` 或 `H·V` 接近 1，F 接近 0，高光颜色保持 R。擦着轮廓看时点积接近 0，F 接近 1，颜色变成白，再乘灯的高光色。Blinn-Phong 打开时用 H，关掉时用法线。

循环外面第 105 行还有一次 `materialSpecularColor = p3d_Material.specular`。循环里第 214 行重新声明了同名变量，外面那个值没有被读过。材质里的 specular 和 shininess 都不参与这张画面。

## 同一盏灯里，谁乘到哪一边

聚光、阴影、衰减都在两份颜色算完之后才施加。顺序是：先算出漫反射和高光，聚光锥外就 `continue`（两份都丢掉），锥内只把指数乘到漫反射上，然后阴影和衰减乘到两边，最后加进累加器。

| 因素 | 漫反射 | 高光 |
| --- | --- | --- |
| 法线、法线贴图、流向 | 用 | 用 |
| `N·L < 0` | 这盏灯直接跳过，高光也不算 | 同左 |
| 漫反射贴图 | 乘 | 不乘 |
| 灯的 diffuse / specular 颜色 | 乘 diffuse | 乘 specular |
| 镜面贴图 R、G、B 和菲涅尔 | 不参与 | 用 |
| 卡通台阶 | `smoothstep(0.1, 0.2)` | `smoothstep(0.9, 1.0)` |
| 聚光锥外 | 丢掉 | 丢掉 |
| 聚光指数 `spotExponent` | 乘 `pow(轴对齐程度, exponent)` | 不乘，锥内保持满强度 |
| 5×5 软阴影 | 乘 | 乘 |
| 距离衰减 | 乘 | 乘 |
| 粒子 | 保留，并乘顶点色 | 乘 0，输出再清一次 |
| SSAO、环境光 | 不乘直接光 | 不乘 |
| 边缘光 | 事后乘的是已经累加的漫反射 | 不参与 |

窗户那三盏灯是这个表的具体例子。`generateWindowLight` 里：

- 颜色 `(0.765, 0.573, 0.400)`，和正午太阳的一档颜色相同。着色器里再解码。
- `set_exponent(5)`。锥轴上漫反射不变，靠向边缘按 5 次方变暗。高光没有这个渐变，到锥边界才连同漫反射一起被切掉。
- 视场角 140°，半角 70°，`spotCosCutoff` 约为 `cos(70°)`，约 0.34。
- 衰减 `(1, 0.008, 0)`，也就是 `1 / (1 + 0.008 d)`。10 个单位外大约还剩 0.93，很缓。方向光没有调用 `set_attenuation`。方向光的 `L` 对所有片元相同，距离是方向向量的长度，衰减是一个常数。

阴影对两边一视同仁。`shadowSamples = 2`，在阴影贴图上取 5×5，把 `1 - textureProj` 求平均。结果在白色和深青 `(0.149, 0.220, 0.227)` 之间混合，深青先做 gamma 解码。粒子把阴影权重换成 1，等于不投影。

## 两张输出为什么分开加

循环结束后：

```glsl
out0.rgb = ambient + diffuse + rim + emission;  // 没有高光
out1.rgb = specular;
```

环境光是半球光乘漫反射贴图再乘 SSAO，和直接光的漫反射不是一条路径。边缘光是 `1 - max(N·V, 0)`，卡通时 `smoothstep(0.3, 0.4)`，否则平方再乘 1.2，然后乘已经加总的漫反射。影子里、背光处没有漫反射，也就没有边缘光。

`base-combine.frag` 先按 alpha 叠折射、反射、泡沫，再把高光加上去：

```glsl
color = mix(base, refraction, refraction.a);
color = mix(color, reflection, reflection.a);
color = mix(color, foam, foam.a);
color.rgb += specular.rgb * clamp(specular.a, 0, 1);
```

所以高光盖在水面填充之后，不会被折射或泡沫的 `mix` 吃掉。水的 `out0.a` 被写成 0，但那只影响底色这张图的 alpha；高光那张图的 alpha 仍是漫反射贴图的 alpha，水面高光还在。

粒子在循环里已经把高光乘了 0，写出 `out1` 时再把 rgb 清成 0。

单盏灯的漫反射和高光各自夹到 1，加总之后不再夹。合成发生在线性空间。整条后期链保持线性，直到 `gamma-correction.frag` 用 `pow(c, 1/2.2)` 编码给窗口。

## 写了但没有参加计算的量

这些名字在 `base.frag` 或 `main.cxx` 里能看到，漫反射和高光的结果不读它们。

| 名字 | 情况 |
| --- | --- |
| `p3d_Material.specular`、`p3d_Material.shininess` | 光泽和颜色改由镜面贴图 G、R 决定 |
| `p3d_Material.diffuse`、`p3d_Material.ambient`、`p3d_LightModel` | 漫反射用贴图，环境光用手写的半球色 |
| 第 105 行的 `materialSpecularColor` | 被循环内的同名变量盖住，值没有往下传 |
| `specularOnly` | `main.cxx` 传了 `(0, 0)`，着色器主体没有读 |
| `p3d_LightSource[i].color`、`.ambient` | 灯的颜色从 `.diffuse` 和 `.specular` 读。演示只调用 `set_color`，Panda 把这份颜色填进这两个槽 |

`material-specular.frag` 会把材质高光色和 `shininess / 127.75` 画成颜色，但主链没有加载它。
