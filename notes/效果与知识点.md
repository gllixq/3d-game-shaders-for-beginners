# 按效果整理的知识点

这份笔记按**画面上的效果**来组织。每个效果只写理解它和对照源码所需要的知识点：它依赖什么、演示里实际怎么算、接在哪一个 pass 后面、对应哪个文件。

章节（`sections/*.md`）是教学用的简化写法，采样器编号和合成顺序经常和演示不一样。槽位、公式系数、pass 依赖以 `demonstration/shaders/` 和 `demonstration/src/main.cxx` 为准。

许可只覆盖 `.cxx`、`.vert`、`.frag`。这里是根据这些源码整理的说明，不是书的正文。

## 怎么读

每个效果固定四小节：

- **依赖的知识点**：不先有这些，这个效果的代码对不上。
- **演示里怎么做**：对着着色器的算法，含关键常数。
- **接在哪里**：输入纹理、输出纹理、和谁合成。
- **源码和开关**：文件与按键。

共用前提放在最前面。后面的效果会点名它用了哪一条，不再重复展开。

## 共用前提

### 坐标系

所有向量先问原点在哪。

| 空间 | 原点 | 本仓库里谁用 |
| --- | --- | --- |
| 模型 | 模型自身，通常在几何中心 | 顶点 `p3d_Vertex`、切线、法线 |
| 世界 | 场景 | 半球环境光要把法线变回世界再和 Z 轴点乘；Panda3D 是 Z 向上 |
| 观察 | 当前相机 | 光照、雾、SSAO、反射、折射、泡沫的位置和法线 |
| 裁剪 | 相机胶片中心，齐次坐标约在 [-1, 1] | `gl_Position` |
| 屏幕 | 左下角，像素或 0 到 1 的 UV | 所有后期 pass，`gl_FragCoord.xy / textureSize` |

顶点着色器的变换是：

```glsl
vertexPosition = p3d_ModelViewMatrix * p3d_Vertex;          // 观察空间
gl_Position    = p3d_ProjectionMatrix * vertexPosition;     // 裁剪空间
```

`p3d_NormalMatrix` 是 ModelView 逆转置的左上 3×3，用来把法线、切线、副切线变到观察空间。法线不能直接乘 ModelView，非均匀缩放会把法线带歪。

`gl-coordinate-system default` 让着色器不用再在 Panda 的 Z 向上和 OpenGL 的 Y 向上之间翻译。`position.frag` 里留了一段把 `xyz` 重排成 `xzyw` 的注释，主链没有启用。

### 观察空间里用 Y 当深度

在这套配置下，**观察空间的 Y 越大，离相机越远**。雾、SSAO、屏幕空间光线步进都在比 `position.y`，不是比 OpenGL 默认的 -Z。

一个片元最多写一个像素，一个像素可以被多个片元盖住。延迟光照省的就是这件事：几何剔除之后，每个像素只照一次。

### 两套帧缓冲

1. **场景相机**。走模型的每个顶点。几何缓冲和 `base.frag` 光照用这套。
2. **屏幕四边形**。`basic.vert` 只做 MVP，正交相机对着一块铺满屏幕的矩形。从雾开始的后期都是这套（`useScene = false`）。可以把它想成往上一层贴一张全屏图。

主相机挂了 `discard.frag`，真正画到窗口上的是最后一张色差纹理。

### 三张几何缓冲

水和烟是半透明的，一张 G-buffer 留不住「看穿它们之后」的位置，所以拆成三次绘制，用相机 mask 把物体分开。

| 缓冲 | 相机 mask | 藏掉谁 | 输出 |
| --- | --- | --- | --- |
| 几何 0 | bit 1 | 水、烟 | 视空间位置、法线 |
| 几何 1 | bit 2 | 烟；水用 tag 换上流向和泡沫图案 | 位置、法线、反射 mask、折射 mask、泡沫 mask |
| 几何 2 | 烟的 tag | — | 把烟叠进几何 1 的位置，并写烟雾 mask |

几何 0 给 SSAO，也给折射光线去碰「水面背后」的表面。几何 1 给反射、折射起点和法线。几何 2 给雾和运动模糊一个包含烟的位置。

材质槽在所有模型上顺序相同，着色器才能通用：

| 采样器 | 内容 | 通道约定 |
| --- | --- | --- |
| `p3d_Texture0` | 漫反射 | 按完全照亮来画；进 `base.frag` 后做 gamma 解码 |
| `p3d_Texture1` | 法线 | 切线空间。平直法线是 (128, 128, 255)，解开是 (0, 0, 1) |
| `p3d_Texture2` | 高光 | R 高光颜色，G 光泽，B 菲涅尔指数 |
| `p3d_Texture3` | 反射 mask | R 强度，G 粗糙（拿来和模糊反射混合） |
| `p3d_Texture4` | 折射 mask | R 标出折射表面 |

UV 在顶点里输出，片元拿到的是三角形内插值，U 和 V 都在 0 到 1。漫反射用 `p3d_MultiTexCoord1`，法线用 `p3d_MultiTexCoord0`。

### 颜色一直保持线性，直到倒数第二步

`framebuffer-srgb` 关闭，gamma 是手算的。`gamma` 这个 uniform 是二元组 `(2.2, 1/2.2)`：

- `pow(c, gamma.x)`：sRGB 贴图解码进线性空间。
- `pow(c, gamma.y)`：线性结果编码回 sRGB，给显示器。

光照、雾的混合、泛光的相加都在线性空间。LUT 和色调分离会临时编码到 sRGB 里量化，再解码回来。真正写给窗口的编码发生在 `gamma-correction.frag`，它在色差之前。

### 光源约定

顶点着色器里 `NUMBER_OF_LIGHTS` 是 4：一盏方向光加三盏窗户聚光。太阳和月亮互斥，谁的亮度大于 0 谁才 `set_shadow_caster` 并挂到场景上。环境光不进 `p3d_LightSource` 数组。

方向光没有位置。Panda3D 把 `position.w` 设为 0，`position.xyz` 设为 `-direction`。于是同一行对三种光都成立：

```glsl
L = position.xyz - vertexPosition.xyz * position.w;
```

点光和方向光的 `spotCosCutoff` 是 -1，点积永远不小于它，锥测试形同跳过。它们的 `spotExponent` 是 0，代码直接不乘，避免 `pow(x, 0)`。

### 主链的真实顺序

下面是 `set_sort` 表达的依赖，不是 Tab 调试列表的顺序。Tab 只是把缓冲塞进一个数组，方便来回看。

```text
几何0 ──► SSAO ──► SSAO 模糊（Kuwahara, size 1）──► 光照 base
几何1 ──► 反射 UV、折射 UV、泡沫
几何1 ──► 几何2 ──► 雾
光照 base ──► 折射取色 ──► 反射取色 ──► 反射模糊 ──► 反射合成
                                           │
光照 base + 折射 + 泡沫 + 反射 + 高光 ──► base-combine
        └──► 锐化 ──► 色调分离 ──► 泛光
                         │
                         └──► 场景合成（色调分离 + 泛光 + 雾 + 天空）
                                └──► 失焦模糊 ──► 膨胀 ──► 景深
                                       └──► 描边 ──► Kuwahara 油画
                                              └──► 像素化 ──► 运动模糊
                                                     └──► 胶片颗粒 ──► LUT
                                                            └──► Gamma ──► 色差 ──► 窗口
```

水在 `base.frag` 里被写成 alpha 0。`base-combine` 再用折射、反射、泡沫的 alpha 把水填回去，最后加上单独一张的高光。

## 漫反射与 Phong 高光

表面朝向光的程度，加上朝向反射方向的高光斑。对着色器逐项拆开的说明在 [漫反射与高光](漫反射与高光.md)。

**依赖的知识点**

- 观察空间的位置和单位法线。
- 四个向量：L 从片元指向光，N 法线，R 反射，V 从片元指向相机（观察空间里就是 `-position`）。
- 点积：同向为 1，垂直为 0，反向为 -1。光照只取不小于 0 的部分。
- 漫反射贴图按「完全照亮」绘制，结果还要 clamp 到贴图颜色，避免多盏灯把表面曝白。

**演示里怎么做**

```glsl
Id = dot(N, normalize(L));
if (Id < 0.0) continue;          // 背面不受这盏光
diffuse = clamp(albedo * light.diffuse * Id, 0, 1);
diffuse = clamp(diffuse, 0, albedo);

R  = normalize(-reflect(normalize(L), N));
Is = clamp(dot(V, R), 0, 1);     // Phong
specular = light.specular * pow(Is, specularMap.g * 127.75) * specularMap.r;
```

光泽存在高光贴图的 G 通道，乘上 `MAX_SHININESS`（127.75）。指数越大，高光越紧。

`out0` 是环境光 + 漫反射 + 边缘光 + 自发光。`out1` 只有高光，留给合成阶段再加，这样水的高光不会跟被挖空的底色搅在一起。粒子没有高光。

**接在哪里**

输入是几何缓冲的位置、法线和三张材质贴图，以及已经模糊过的 SSAO。输出 `Base` 和 `Specular` 两张。必须排在 SSAO 模糊之后。

**源码和开关**

`shaders/vertex/base.vert`，`shaders/fragment/base.frag`。按键 `0` 离开 Phong，改走下一节。

## Blinn-Phong

同一套光照，高光改用半角向量。高光更扁，掠射时不容易整块变成 0。

**依赖的知识点**

- Phong 那四个向量里，不再需要 R。
- 半角 H 是 L 和 V 的角平分线。H 与 N 对齐时，V 正好沿着反射方向，两种模型的高光强度都是 1。其他角度 Blinn-Phong 往往还大于 0，Phong 已经是 0。

**演示里怎么做**

```glsl
H  = normalize(normalize(L) + V);
Is = clamp(dot(N, H), 0, 1);
```

光泽、贴图、衰减、阴影与 Phong 共用。菲涅尔在打开时也会改用 H 而不是 N，见菲涅尔一节。

**接在哪里**

同一个 `base.frag`，`blinnPhongEnabled` 在两种高光之间切换。

**源码和开关**

`base.frag`。按键 `0`。

## 阴影

挡住光的表面把后面的片元压暗。

**依赖的知识点**

- 阴影空间：以灯为原点。顶点着色器对每盏灯做 `shadowViewMatrix * vertexPosition`。
- 阴影贴图是从灯看出去的深度图。`sampler2DShadow` 做的是深度比较，不是普通取色。
- `textureProj` 先把 `xyz` 除以 `w`，再用 `xy` 查图、用 `z` 和贴图深度比。通过是 1（照到了），失败是 0（在影子里）。硬件 PCF 可以返回中间值。

**演示里怎么做**

不是单次比较。`shadowSamples = 2`，在阴影贴图上取 5×5 邻域，把 `1 - textureProj` 求平均，得到 `inShadow`。再用一个预先解码进线性空间的深青色去混合白色：

```glsl
shadow = mix(vec3(1.0), shadowColor, inShadow);
diffuse  *= shadow;
specular *= shadow;
```

粒子不乘阴影。影子不是纯黑。

**接在哪里**

算在每盏灯的贡献上，还没累加进 `out0` / `out1` 之前。太阳或月亮亮度降到 0 时，`main.cxx` 会关掉那盏灯的 shadow caster。

**源码和开关**

`base.vert` 写 `vertexInShadowSpaces`，`base.frag` 采样。没有单独的开关，跟着昼夜走。

## 距离衰减与聚光锥

离灯越远越暗；聚光灯锥外不受光。

**依赖的知识点**

- 衰减用的是 L 的长度，不能用已经归一化的 L，否则距离恒为 1。
- 聚光灯同时有位置和方向。`spotDirection` 从灯指向锥轴。比较时要把 L 反过来，因为 L 是从片元指向灯。

**演示里怎么做**

```glsl
attenuation = 1 / (constant + linear * d + quadratic * d * d);
if (dot(normalize(spotDirection), -normalize(L)) < spotCosCutoff) continue;
if (spotExponent > 0) diffuse *= pow(unitLightDirectionDelta, spotExponent);
```

`spotCosCutoff` 约等于 `cos(fov / 2)`。方向光和点光被 Panda3D 设成恒通过。衰减和锥测试同时乘到漫反射和高光上。衰减已经是 0 就直接跳过这盏灯。

**接在哪里**

仍在 `base.frag` 的灯光循环里，阴影之后、累加之前。

**源码和开关**

`base.frag`。窗户那三盏聚光只在夜间亮起来，亮度是夜间系数的 0.4 次方。

## 菲涅尔

表面越侧对相机，高光越接近镜面。正对相机时反射弱。

**依赖的知识点**

- 这是 Schlick 近似的形状：`pow(1 - cosθ, n)`，范围 0 到 1。
- `cosθ` 可以是 `N·V`，也可以是 `H·V`。半角版本和 Blinn-Phong 配套。
- 指数越大，只有轮廓附近才亮。

**演示里怎么做**

高光颜色先取镜面贴图的 R。菲涅尔打开时：

```glsl
F = dot(blinnPhong ? H : N, V);
F = pow(1.0 - max(F, 0.0), specularMap.b * 5.0);
specularColor = mix(specularColor, vec3(1.0), clamp(F, 0, 1));
```

B 通道是 0 到 1 的系数，乘上 `MAX_FRESNEL_POWER`（5）。结果把高光颜色往白色拉，不直接改高光强度的指数。

**接在哪里**

只影响 `out1` 那张高光。屏幕空间反射是另一条路，用反射 mask，不用这个菲涅尔项。

**源码和开关**

`base.frag`。按键 `3`。

## 边缘光

把轮廓照亮，用来勾物体，或者和卡通、描边一起做二次元。

**依赖的知识点**

- 和菲涅尔同一几何事实：`N·V` 在正面接近 1，在轮廓接近 0。边缘光取的是 `1 - N·V`。
- `smoothstep` 把过渡收成一条硬边，适合卡通；`pow` 留下渐变。

**演示里怎么做**

```glsl
rim = 1.0 - max(0.0, dot(V, N));
rim = cel ? smoothstep(0.3, 0.4, rim) : pow(rim, 2.0) * 1.2;
rim *= diffuse;
```

边缘光乘的是已经算好的漫反射，所以影子里、背光处不会平白多出一圈。它加进 `out0`，不进高光缓冲。

**接在哪里**

灯光循环结束之后、环境光之前。

**源码和开关**

`base.frag`。按键 `4`。

## 卡通着色

把连续的明暗切成几档，表面看起来平。

**依赖的知识点**

- 输入仍然是 Lambert 的 `N·L` 和 Phong 或 Blinn 的高光强度。卡通只改强度的形状，不改向量。
- `step` 是硬切，`smoothstep` 留一条窄过渡。章节里还写了多级 if 和一维 ramp 纹理两种做法，演示用的是 smoothstep。

**演示里怎么做**

```glsl
diffuseIntensity  = smoothstep(0.1, 0.2, diffuseIntensity);
specularIntensity = smoothstep(0.9, 1.0, specularIntensity);
```

漫反射几乎是「有光或没光」。高光只留下最亮的芯。边缘光同时改成 `smoothstep(0.3, 0.4, ...)`。

**接在哪里**

仍在 `base.frag`。和描边、色调分离不是同一个 pass。卡通是光照整形，后两者是屏幕空间。

**源码和开关**

`base.frag`。按键 `8`。

## 法线贴图

用贴图换掉低模法线，光照看起来有高模的细节。侧面一看还是平的。

**依赖的知识点**

- 贴图里的法线在切线空间。颜色 0 到 1 对应向量 -1 到 1：`n = tex.rgb * 2 - 1`。
- TBN 的三列是观察空间的切线、副切线、顶点法线。乘上去才变成观察空间，才能和 L、V 点乘。
- 三个向量都要先用 `p3d_NormalMatrix` 变到观察空间再单位化。

**演示里怎么做**

几何缓冲 0 和 1，以及 `base.frag`，都是同一段：

```glsl
n = normalize(normalTex.rgb * 2.0 - 1.0);
n = normalize(mat3(tangent, binormal, vertexNormal) * n);
```

关掉时退回顶点法线。粒子的法线是世界 +Z 变到观察空间，不读贴图。

流向打开时，采样法线贴图的 UV 会加上 `flow * osg_FrameTime`，水面的凹凸跟着动。见流向一节。

**接在哪里**

法线在几何 pass 里就写进法线纹理。光照 pass 再算一遍，因为 `base.frag` 自己也要法线，不读几何缓冲的法线纹理。SSAO、反射、折射读的是几何缓冲那张。

**源码和开关**

`geometry-buffer-0.frag`，`geometry-buffer-1.frag`，`base.frag`。按键 `o`。

## 流向

让流体表面的 UV 随时间平移。法线贴图和泡沫图案都靠它动。

**依赖的知识点**

- 流向图用 R、G 存 XY 平移，和法线贴图一样从 [0, 1] 解开到 [-1, 1]。
- 中性流向是 (0.5, 0.5)，解开是 (0, 0)，表面不动。演示里的 `up-flow.png` 是整张图一个颜色，大约 (0.5, 0.6)，解开后大致沿 +Y 流。

**演示里怎么做**

```glsl
flow = (texture(flowTexture, uv).xy - 0.5) * 2.0;
if (abs(flow.x) <= 0.02) flow.x = 0.0;   // 死区，去掉接近 0 的噪声
if (abs(flow.y) <= 0.02) flow.y = 0.0;
```

水这个节点被 tag 成 `isWater`，流向贴图换成 `up-flow.png`，泡沫图案换成 `foam-pattern.png`。其他物体用 `still-flow.png` 和空白泡沫图。

**接在哪里**

几何 1 用它偏移泡沫图案的 UV。`base.frag` 用它偏移法线贴图的 UV。两者都乘 `flowMapsEnabled * osg_FrameTime`。

**源码和开关**

`geometry-buffer-1.frag`，`base.frag`。按键 `.`。

## 半球环境光

没有直接光时，朝上的面偏天空色，朝下的面偏地面色。这是演示相对章节的一处改写。章节里的环境光是 `material.ambient * lightModel.ambient * albedo`，只算一次。演示换成了随太阳俯仰变化的半球。

**依赖的知识点**

- 世界空间的上方向是 Z，不是 Y。法线要乘观察空间到世界的矩阵。
- `0.5 * (1 + N·up)` 把朝向收成 0（朝下）到 1（朝上）。
- SSAO 只乘环境光，不乘直接光。缝隙变暗，被太阳照到的面不变。

**演示里怎么做**

```glsl
worldNormal = normalize((trans_view_to_world * vec4(N, 0)).xyz);
ambient = mix(groundLight, skyLight, 0.5 * (1 + dot(worldNormal, vec3(0, 0, 1))));
ambient *= albedo * ssao;
```

天空色和地面色随太阳角度对调，并先做 gamma 解码。自发光是材质 emission，再乘太阳高度的 0.4 次方，夜间至少留 0.1。

SSAO 纹理先和阴影色混合：遮蔽强的地方从白掉到深青，再乘上环境光。

**接在哪里**

`out0 = ambient + diffuse + rim + emission`。水的 `out0.a` 被设为 0。

**源码和开关**

`base.frag`。环境光没有单独按键。SSAO 的开关是 `y`，关掉后这张纹理保持白色，环境光不再被压暗。

## SSAO

用屏幕上已有的位置和法线，估计缝隙有多少环境光进不来。静态场景可以烘贴图，会动的场景用这个。

**依赖的知识点**

- 输入都在观察空间：位置、法线、投影矩阵。
- 采样向量在切线空间的半球里（Z 从 0 到 1）。噪声向量把半球随机转一下，否则条带很明显。
- 深度比较用观察空间的 Y。采样点的 Y 比该像素上记录的表面更远，就算被挡住。
- 样本沿半径平方分布，靠近表面更密：`scale = lerp(0.1, 1.0, t * t)`。

**演示里怎么做**

8 个样本，4 个噪声，半径 0.6，bias 0.005。每个样本用 TBN 变到观察空间，加上 `position`，再投影回屏幕 UV 去读位置纹理。

```glsl
occluded = (sample.y + bias <= recorded.y) ? 0 : 1;
occluded *= smoothstep(0, 1, radius / abs(position.y - recorded.y));
occlusion = pow(occlusion / NUM_SAMPLES, 1.1);
occlusion = 1.1 * (occlusion - 0.5) + 0.5;
```

距离差很大的遮蔽被 `smoothstep` 减弱，避免远处的大面误伤。位置 alpha 为 0 的像素（背景）直接输出白。

原始 SSAO 很噪，下一张缓冲用 Kuwahara、`size = 1` 抹平。油画效果用的是同一个着色器，核更大。

**接在哪里**

读几何 0 的位置和法线，所以水本身不参与遮蔽。结果进 `base.frag` 的环境光。必须在光照之前。

**源码和开关**

`ssao.frag`，样本在 `main.cxx` 的 `generateSsaoSamples`。按键 `y`。

## 雾

远处的物体渐隐进大气色，也用来挡住物体突然进入远平面时的弹出。

**依赖的知识点**

- 线性雾：`(distance - near) / (far - near)`，再 clamp。指数雾是另一种模型，这里没用。
- 距离取观察空间 Y，并且减去场景原点在相机空间里的 Y。几何 2 没写到的像素，Y 被拉到 far，雾最浓。
- 雾先画进自己的纹理，颜色在 RGB，强度在 A。合成时 `mix(scene, fogColor, fog.a)`。这样只算一次。

**演示里怎么做**

`fogMin = 0`，`fogMax = 0.97`，再浓也留一点场景。雾的颜色不是常数，而是两层背景色按屏幕 V 和一点哈希混合，再乘太阳高度，和天空同一套做法。烟的 mask 会在几何 0 和几何 2 的位置之间混合，烟柱也吃到雾。

**接在哪里**

雾 pass 紧跟几何 2，但要到场景合成才用上。场景合成在色调分离和泛光之后，所以雾盖住的是已经加过泛光的图。描边会读雾的 alpha，雾浓的地方少画线。

**源码和开关**

`fog.frag`，合成在 `scene-combine.frag`。按键 `p`。`[` 和 `]` 调近远，按住 Shift 方向相反。

## 屏幕空间反射

让水面和金属映出场景里的其他东西，而不只是光源的高光斑。

**依赖的知识点**

- 高光是光源的反射。SSR 是场景颜色的反射：光线从别的表面进来，在当前片元弹向相机。着色器沿这条路倒着找。
- 反射向量 `reflect(I, N)`。这里 I 用的是归一化后的观察空间位置（从相机指向片元）。
- 射线步进：在起点和最远点之间逐步取样，把观察空间点投影回屏幕，看那一像素的表面深度是否刚好被射线穿过。
- 只在屏幕上找。反射点出了屏幕、被别人挡住、或者步进跨过了薄的物体，就会失败。这是方法的边界，不是参数没调好。

**演示里怎么做**

只在反射 mask 的 R > 0 且位置有效时步进。最远 8，分辨率 0.3，厚度 0.5，命中后再二分 5 步。

可见性乘了几项：是否命中、命中点的 alpha、射线和视线不要太平、命中深度落在厚度里、距离不超过 maxDistance、UV 还在 0 到 1。结果写在 UV 纹理的 `xy`（命中坐标）和 `ba`（可见性）。

`reflection-color.frag` 用这个 UV 去采样颜色。UV 无效时先在 13×13 的窗口里把邻居 UV 平均一下，补洞。然后：

```glsl
color = texture(scene, uv.xy);
alpha = clamp(uv.b, 0, 1);
```

这张颜色再被盒模糊（size 8，separation 1）出一张模糊版。`reflection.frag` 用 mask 的 G 当粗糙度，在清晰和模糊之间混合，再乘 R 当强度。

反射采的颜色是**已经做过折射的图**，所以水里的折射会进到别的反射表面上。

**接在哪里**

UV 来自几何 1 的位置和法线。取色在折射取色之后。合成进 `base-combine`，按 alpha 盖到基础色上，顺序是先折射、再反射、再泡沫。

**源码和开关**

`screen-space-reflection.frag`，`reflection-color.frag`，`reflection.frag`，模糊用 `box-blur.frag`。按键 `m`。

## 屏幕空间折射

透明物体后面的场景沿折射方向偏移。玻璃、水和塑料靠这个。

**依赖的知识点**

- 和反射同一套步进，方向从 `reflect` 换成 `refract(I, N, eta)`。`eta` 是相对折射率。
- 必须有两套位置：含水面的起点（几何 1），和不含水面的被命中表面（几何 0）。不然射线会撞到水面自己。
- 折射进水之后，颜色还要随穿过的厚度变深。厚度是两个位置之差的长度，不是屏幕上的距离。

**演示里怎么做**

步进参数比反射近一些：最远 5，分辨率 0.3，厚度 0.5，二分 5 步。默认 `rior = 1.05`。

UV pass 输出的是 `mix(原来的屏幕 UV, 命中 UV, visibility)`，所以没打中时退回不折射。取色时：

```glsl
mixture = clamp(length(positionTo - positionFrom) / 2.0, 0, 1);
deep    = mix(background, tint, 0.8);
color   = mix(background, deep, mixture);
```

水色是 (0.392, 0.537, 0.561)，先解码再乘太阳高度。背景色采样的是 `base` 光照结果，沿命中 UV 去取，所以看到的是背后已经照过光的表面。

**接在哪里**

排在光照之后、反射取色之前。`base-combine` 第一个 `mix` 就是它。水在 base 里 alpha 为 0，这里把洞填上。

**源码和开关**

`screen-space-refraction.frag`，`refraction.frag`。按键 `,`。`=` 增大折射率，Shift+`=` 减小，步进 0.005。

## 泡沫

水变浅的地方堆白边，把水面和岸接到一起。同一算法可以把边缘做成岩浆。

**依赖的知识点**

- 仍然要两套位置：水面（几何 1）和水底（几何 0）。
- 泡沫量由深度差决定，不是由一张手绘的岸边遮罩单独决定。mask 只负责「哪里允许有泡沫」以及图案。
- 演示把两个位置变回世界再取长度。章节里的简化是只减观察空间的 Y。

**演示里怎么做**

```glsl
depth  = length(positionTo.xyz - positionFrom.xyz);
amount = 1.0 - clamp(depth / foamDepth, 0, 1);
amount *= mask.r;
amount = (amount * amount) / (2 * (amount * amount - amount) + 1);  // 缓入缓出
```

默认 `foamDepth = 1.5`。颜色 (0.8, 0.85, 0.92)，alpha 0.8，随太阳变暗。mask 来自几何 1：泡沫图案的 UV 被法线偏移，再被流向推着走。mask 的 R 为 0 就直接输出透明。

**接在哪里**

可以和几何 1 并行，不依赖光照。合成时盖在反射之上，所以泡沫压过倒影。

**源码和开关**

`foam.frag`，图案 UV 在 `geometry-buffer-1.frag`。`-` 增加泡沫深度，Shift+`-` 减少，步进 0.1。

## 把水填回去

这不是一个单独的画面风格，而是折射、反射、泡沫能同时出现的原因。

**依赖的知识点**

- 水在光照 pass 的 alpha 是 0，底色那里是个洞。
- 每张效果纹理用自己的 alpha 表示覆盖程度。`mix(dst, src, src.a)` 就是按这个覆盖。
- 高光是加，不是 mix。加在最后，水上的高光斑还在。

**演示里怎么做**

```glsl
color = base;
color = mix(color, refraction, clamp(refraction.a, 0, 1));
color = mix(color, reflection, clamp(reflection.a, 0, 1));
color = mix(color, foam,       clamp(foam.a,       0, 1));
color += specular * clamp(specular.a, 0, 1);
```

顺序就是视觉上的上下层：折射在最底，反射盖上来，泡沫再盖上来。

**接在哪里**

`base-combine` 之后才进入锐化及后面的风格化。所以卡通以外的屏幕效果看到的水，已经是填好的。

**源码和开关**

`base-combine.frag`。没有单独按键，跟着 `m`、`,` 和泡沫深度走。

## 锐化

加大相邻像素的反差，边缘更清楚。

**依赖的知识点**

- 一个十字卷积核。中心权重大于 1，四邻为负，权重和为 1 时整体亮度不变。
- `amount` 为 0 时核退化成「只留中心」。负的 amount 会反过来把边缘抹平。

**演示里怎么做**

`amount = 0.3`。中心权重 `0.3 * 4 + 1 = 2.2`，每个邻居 `-0.3`。只改 RGB，alpha 原样抄。

**接在哪里**

`base-combine` 的下一张。色调分离读的是锐化结果。关掉时原样通过。

**源码和开关**

`sharpen.frag`。按键 `l`。

## 色调分离

把连续颜色收成有限的几档，偏海报或漫画。

**依赖的知识点**

- 量化在感知空间里做比较均匀，所以先编码到 sRGB，分档，再解码回线性。
- 演示不直接把 RGB 各自取整，而是用 `max(R, G, B)` 当灰度，找到最近的一档，再把 RGB 按同一个比例缩放。色相比「每个通道各切一刀」更稳。
- 背景（位置 alpha 为 0）不处理，输出黑，留给后面的天空合成。

**演示里怎么做**

`levels = 6`。

```glsl
color = pow(color, 1/2.2);
grey  = max(color.r, max(color.g, color.b));
lower = floor(grey * levels) / levels;
upper = ceil(grey * levels) / levels;
level = (grey - lower <= upper - grey) ? lower : upper;
color *= level / grey;
color = pow(color, 2.2);
```

**接在哪里**

锐化之后。泛光和场景合成的底图都是这张，所以泛光提取的是已经分档的颜色。

**源码和开关**

`posterize.frag`。按键 `j`。

## 泛光

亮部晕开，发光体和高光更像真的在发光。

**依赖的知识点**

- 先用阈值把暗部丢掉，再对剩下的颜色做盒模糊，最后按数量加回，不是 mix。
- 盒模糊是窗口里的算术平均。窗口边长 `size * 2 + 1`。`separation` 把采样点拉开，不增加样本数。
- 加色必须在线性空间。阈值也是在线性颜色上比的。

**演示里怎么做**

`size = 3`（7×7），`separation = 4`，`threshold = 0.6`，`amount = 0.6`。亮度用 `max(R, G, B)`。低于阈值的样本记 0，但仍然计入平均，所以晕光会被暗邻居拉低。关掉或 size 小于等于 0 时输出全 0，场景合成加上去也没有变化。

**接在哪里**

读色调分离的结果，写出一张只有亮晕的图。`scene-combine` 做 `base + bloom`，底图仍是色调分离，不是锐化前的图。

**源码和开关**

`bloom.frag`，核的定义和 `box-blur.frag` 相同，但是内联的，并且多了阈值。按键 `i`。

## 场景合成

把分档后的场景、泛光、雾和天空叠成一张完整的画。

**依赖的知识点**

- 泛光是加。雾是按 alpha 的 mix。天空用场景和雾的 alpha 当遮罩：没有几何、雾也不浓的像素露出天空。
- 天空的做法和雾色相同：两种背景色按屏幕高度加一点哈希抖动，再乘太阳高度，蓝色在太阳低时略抬。

**演示里怎么做**

```glsl
color = posterized + bloom;
color = mix(color, fog.rgb, min(fog.a, 1));
color.rgb = mix(sky, color.rgb, min(posterized.a + fog.a, 1));
color.a = 1;
```

这里开始，后面的 pass 都有不透明的 alpha。位置纹理仍然可以拿来判断「原来是不是背景」，描边、色调分离、像素化都还握着几何 2 的位置。

**接在哪里**

色调分离和泛光之后，景深之前。所以景深模糊的是已经有雾和天空的图。

**源码和开关**

`scene-combine.frag`。没有单独按键。

## 景深

焦点附近清楚，离开焦点逐渐用一张全虚的图替换。

**依赖的知识点**

- 两张输入：完全清晰的颜色，完全失焦的颜色。失焦不是在景深着色器里现算模糊，而是前两张缓冲已经做好。
- 模糊量是当前片元到焦点的**三维距离**，不是屏幕距离，也不是深度差。焦点是中键点下的那个像素在位置纹理里的观察空间位置。
- `smoothstep(min, max, distance)` 把距离收成 0 到 1 的混合系数。

**演示里怎么做**

`minDistance = 8`，`maxDistance = 12`。清晰图是场景合成。失焦图是场景合成先做盒模糊（size 2，separation 2），再做圆形膨胀（size 4，separation 2）。

```glsl
blur = smoothstep(8, 12, length(position - focusPoint));
color = mix(sharp, outOfFocus, blur);
```

第二张输出就是这个 `blur`，给描边用：越虚的地方越不画线。背景像素把 blur 记成 1。关掉景深时第二张输出不会更新，描边仍可能读到旧的 blur。

**接在哪里**

场景合成之后、描边之前。运动模糊在更后面，两者会叠。

**源码和开关**

`depth-of-field.frag`。按键 `h`。中键设置焦点，色差的中心也是这个点。

## 膨胀

窗口里较亮的颜色向外扩，看起来发肿、像枕头。在这条管线里它专门喂给景深的失焦层。

**依赖的知识点**

- 和模糊相反：模糊是平均或中值，膨胀是取窗口内最亮的样本（灰度用 0.30 R + 0.59 G + 0.11 B）。
- 窗口形状会变成膨胀后的形状。演示用的是圆：`distance(offset, 0) <= size`。源码里留了矩形和菱形的注释。
- `smoothstep(minThreshold, maxThreshold, maxLuma)` 决定扩多少。暗的区域几乎不动。

**演示里怎么做**

`minThreshold = 0.2`，`maxThreshold = 0.5`。景深这条链上 size 4、separation 2。size 小于等于 0 时原样返回。

**接在哪里**

失焦模糊之后、景深混合之前。不单独显示成最终画面，除非用 Tab 去看 `Dilation`。

**源码和开关**

`dilation.frag`。没有单独按键，跟着景深的输入走。景深关掉后这张图仍会算，只是不被混合。

## 描边

在深度不连续的地方把颜色压暗，勾出轮廓。

**依赖的知识点**

- 描边就是找不连续。演示找的是观察空间位置的 Y 差，不是法线，也不是颜色。
- 线的强弱还要乘「这里有多清晰」和「这里雾有多稀」。虚焦和浓雾里不画线。
- 采样点加了一点噪声纹理，线不会是完全整齐的像素阶梯。

**演示里怎么做**

邻域 size 1。分离度随深度从 1 变到 1，实际上是固定的。Y 差经过 `smoothstep(1.5, 2.0, maxDelta)`。线的颜色是原来的颜色乘上 (0.522, 0.431, 0.349)，先做 gamma 解码，所以线是压暗而不是另画一条黑边。

背景的 Y 被换成 far，物体和天空的交界也会产生深度差。

**接在哪里**

景深之后。它读的是景深的颜色、景深的 blur 输出、雾和几何 0 的位置。Kuwahara 油画读的是描边结果，所以油画会把线一起抹开。

**源码和开关**

`outline.frag`。按键 `u`。

## Kuwahara 油画

一种保边的模糊。平坦区域被抹平，边缘留下来，看起来像颜料块。

**依赖的知识点**

- 以当前像素为中心划四块子窗口（左下、右下、左上、右上）。
- 每块算颜色均值，以及灰度的方差。灰度权重是 (0.30, 0.59, 0.11)。
- 输出方差最小的那块的均值。跨边缘的那块方差大，会被丢掉，所以边还在。

**演示里怎么做**

`size` 是子窗口半径，最大 5。size 小于等于 0 时直接返回原图。

它被用了两次：

- SSAO 模糊，size 固定为 1，一直开着。
- 油画 pass，默认 size 0。按键 `7` 在 0 和 3 之间切。

**接在哪里**

油画 pass 在描边之后、像素化之前。SSAO 那次在光照之前，和油画无关。

**源码和开关**

`kuwahara-filter.frag`。按键 `7`。

## 像素化

把画面收成大方块，用来做复古感，而不必每块像素都手绘。

**依赖的知识点**

- 块的大小必须是奇数，这样每一块有唯一的中心像素。
- 当前片元归到自己所在块，改去采样那块中心。同一块里的片元读到同一个颜色。
- 背景不像素化，避免天空也被打成格子。判断用几何 2 的位置 alpha。

**演示里怎么做**

`pixelSize = 5`。

```glsl
x = gl_FragCoord.x + (floor(pixelSize / 2) - (int(gl_FragCoord.x) % pixelSize));
```

Y 同样处理，再除以纹理尺寸去采样。

**接在哪里**

油画之后、运动模糊之前。运动模糊采样的是已经像素化的颜色，拖影也是一块一块的。

**源码和开关**

`pixelize.frag`。按键 `k`。

## 运动模糊

用前后两帧的位置差当拖影方向，卖速度。

**依赖的知识点**

- 演示实现的是**相机运动**：同一观察空间位置，用上一帧的 view-to-world 和当前的 world-to-view 求它上一帧在屏幕上的位置。物体自己在动、相机不动时，这条做不出拖影。原理一样，只是位置差要来自物体，而不是只来自相机矩阵。
- 两帧位置都要投影到屏幕 UV，方向是 `当前 UV - 上一帧 UV`。
- 沿这个方向向前向后各采样 `size` 次，连同中心一起平均。

**演示里怎么做**

`size = 2`，`separation = 1`，所以中心加前后各 2 个样本，共 5 个，再除以 5。位置 alpha 为 0、方向长度为 0、或开关关闭时，保持原色。

位置来自几何 2，所以烟的拖影跟着烟的位置走。颜色来自像素化之后的图。

**接在哪里**

像素化之后、胶片颗粒之前。每帧 `main.cxx` 把当前 view-world 矩阵留到下一帧。

**源码和开关**

`motion-blur.frag`。按键 `6`。默认关。

## 胶片颗粒

给颜色加一层每帧都变的细噪声。演示里加得很轻。

**依赖的知识点**

- 噪声必须跟着帧变，否则就是一张固定的脏贴图。这里用 `osg_FrameTime`。
- `sin` 的值域是 [-1, 1]，外面乘一个大数再 `fract`，得到 0 到 1 的哈希。章节里还讲了把一个坐标再乘一个系数来打散对角纹，演示这版没有做那一步。

**演示里怎么做**

```glsl
amount = 0.01 * fract(10000 * sin((gl_FragCoord.x + gl_FragCoord.y * osg_FrameTime) * pi.y));
color.rgb += amount;
```

`pi.y` 是角度转弧度的系数，在这里只是哈希的一个缩放。噪声只往上加，不对称地压暗。

**接在哪里**

运动模糊之后、LUT 之前。加在线性颜色上。

**源码和开关**

`film-grain.frag`。按键 `n`。

## LUT

用一张查色表把颜色整个换掉。校色、日夜色调都可以做成图，不必改光照。

**依赖的知识点**

- 表是 256×16，里面 16 块，每块 16×16。蓝色选哪一块，块内红色向右、绿色向下。左上角第一块是黑，右下角最后一块是白。中性 LUT 查出来等于输入。
- 蓝色只有 16 级，所以要在相邻两块之间按小数部分插值。红和绿同样在 `floor` 和 `ceil` 之间插。
- 查表发生在 sRGB。进来先 `pow(c, 1/2.2)`，查完再 `pow(c, 2.2)` 回到线性，免得后面的 gamma pass 重复编码。

**演示里怎么做**

有两张 LUT，`lookup-table-0` 和 `lookup-table-1`。太阳俯仰先变成 0 到 1，再在两张表的结果之间混合，所以色调跟着昼夜走，不是只靠按键换一张图。

**接在哪里**

胶片颗粒之后、gamma 编码之前。

**源码和开关**

`lookup-table.frag`，图在 `demonstration/images/lookup-table-*.png`。按键 `9`。

## Gamma 校正

让前面所有线性空间里的加减乘在显示器上看起来是对的。没有它，暗部糊成一块，亮部发飘。

**依赖的知识点**

- sRGB 是编码，线性 RGB 才是光的权重。贴图文件多半是 sRGB，光照公式要的是线性。
- 解码是 `pow(c, 2.2)`，编码是 `pow(c, 1/2.2)`。2.2 就是 gamma。
- 解码会把颜色变暗。如果在已经是线性的缓冲上再解码一次，画面会发灰发黑。这条管线只在「读 sRGB 贴图」和「临时去感知空间量化」时解码。

**演示里怎么做**

最后这张 pass 做的只有编码：

```glsl
fragColor.rgb = pow(texture(colorTexture).rgb, vec3(1.0 / 2.2));
```

贴图解码散落在 `base.frag`（漫反射、光源色、环境色、自发光相关的常数色）以及雾、折射、泡沫、描边。

**接在哪里**

LUT 之后、色差之前。色差看到的已经是 sRGB。窗口上显示的是色差的输出，不会再编码一次。

**源码和开关**

`gamma-correction.frag`。没有开关。`GAMMA` 在 `main.cxx` 里是 2.2。

## 色差

三个颜色通道沿不同偏移取样，模仿镜头没把波长对齐。

**依赖的知识点**

- 这是屏幕空间的采样偏移，不涉及场景几何。
- 偏移可以是水平、垂直或径向。演示是径向：方向是当前像素指向焦点的向量。焦点和景深共用中键那个点，所以色差从点击处向外散。
- 三个通道的偏移不同，甚至可以反号。

**演示里怎么做**

```glsl
direction = texCoord - mouseFocusPoint;
color.r = texture(texCoord + direction *  0.009).r;
color.g = texture(texCoord + direction *  0.006).g;
color.b = texture(texCoord + direction * -0.006).b;
```

关掉时三个通道都用原来的 UV。

**接在哪里**

整条链的最后一环，输入是已经 gamma 编码的图。主窗口显示这张纹理。

**源码和开关**

`chromatic-aberration.frag`。按键 `\`。

## 盒模糊

窗口内颜色的平均。快，但是边也会一起糊掉。

**依赖的知识点**

- 样本数是 `(size * 2 + 1)²`。`separation` 至少为 1，用来拉开采样。
- 平均是把 RGB 相加再除以样本数。alpha 保持中心像素的 alpha。

**演示里怎么做**

`box-blur.frag` 本身没有阈值。用到它的地方：

| 调用 | size | separation | 作用 |
| --- | --- | --- | --- |
| 反射颜色 | 8 | 1 | 粗糙反射 |
| 景深的失焦图 | 2 | 2 | 全画面变虚 |

泛光的核是同一算法，但写在 `bloom.frag` 里，并且先按阈值把暗样本清零。

**源码和开关**

`box-blur.frag`。没有单独按键。

## 中值滤波

用样本的中值代替均值。脉冲噪声不会把整块颜色拉走，边缘比盒模糊稳。

**依赖的知识点**

- 真中值要排序。着色器里用分箱近似，换线性时间。`MAX_SIZE` 是 4，`MAX_BINS_SIZE` 是 10。
- 它是书里的一种模糊，不是主链的一环。`main.cxx` 没有加载 `median-filter.frag`。

**源码和开关**

`median-filter.frag`。演示里看不着，Tab 也没有这张缓冲。

## 没有挂进主链的着色器

这些文件和书上的某一节对应，或者是调试输出。`loadShader` 没有引用它们。

| 文件 | 做什么 |
| --- | --- |
| `discard.frag` | 主相机把片元丢掉。真正的画面来自色差那张纹理 |
| `position.frag` | 把观察空间位置写成颜色，留了 Z 向上转 Y 向上的注释 |
| `normal.frag` | 单独输出法线，含流向偏移 |
| `material-diffuse.frag` | 只输出材质漫反射色 |
| `material-specular.frag` | 只输出材质高光色 |
| `foam-mask.frag` | 单独算泡沫图案 UV。主链把这段写进了几何 1 |

## 昼夜只改几项数据

太阳绕 X 轴转。俯仰 270° 是正午，90° 是午夜。`1` 和 `2` 把俯仰钉死，`/` 开关动画，`r` 重置。

同一套 `mixFactor` 同时驱动：

- 太阳和月亮谁亮、谁投射阴影。
- 三盏窗户聚光的亮度。
- 窗板开合的动画。
- 半球环境光的冷暖。
- 雾色、天空、水色、泡沫色。
- 两张 LUT 的混合。

所以「夜晚」不是另换一个着色器，而是这些效果读了同一个太阳角度。
